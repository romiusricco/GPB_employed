# Работа в GPB

Промостраница о работе в Газпромбанк.Тех. Включает первый экран, блок мотивации и информацию в подвале.

<!-- Скриншот: ./docs/screenshot.png — добавить изображение, когда оно будет готово. -->

## Быстрый старт

- Откройте `index.html` в браузере.
- В VS Code можно открыть проект через расширение Live Server.

## Стек

- HTML
- SCSS и собранный CSS
- SVG-спрайт и отдельные SVG-иконки
- Шрифт Unbounded Light в форматах WOFF и WOFF2

## Возможности страницы

- Первый экран с заголовком и текстом о Газпромбанк.Тех.
- Блок «Мощная мотивация» с двумя пунктами.
- Шапка с кнопкой-бургером и SVG-иконками открытия и закрытия; действие кнопки требует уточнения.
- Подвал с информацией о банке и ссылкой на политику обработки персональных данных.

## Структура проекта

- `index.html` — разметка страницы.
- `css/style.css` — стили, подключённые страницей.
- `scss/` — исходные SCSS-файлы: глобальные стили и блоки страницы.
- `images/sprite.svg`, `images/sprite/` — SVG-спрайт и иконки.
- `fonts/` — файлы шрифта Unbounded Light.
